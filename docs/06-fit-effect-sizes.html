7.2 Proportional reduction in variance

The most interpretable multilevel effect sizes ask how much variance a model explains relative to the null model, computed separately at each level. Extract the variance components first:

vc_null <- as.data.frame(VarCorr(m_null))
vc_cond <- as.data.frame(VarCorr(m_cond))

tau_null   <- vc_null$vcov[vc_null$grp == "strs3"]
sigma_null <- vc_null$vcov[vc_null$grp == "Residual"]

tau_cond   <- vc_cond$vcov[vc_cond$grp == "strs3"]
sigma_cond <- vc_cond$vcov[vc_cond$grp == "Residual"]

c(tau_null = tau_null, sigma_null = sigma_null,
  tau_cond = tau_cond, sigma_cond = sigma_cond)
  tau_null sigma_null   tau_cond sigma_cond 
 0.7675085  0.1325110  0.5055268  0.1051911

Within-group proportional reduction in variance is the share of student-level variance the predictors account for:

wg_prv <- (sigma_null - sigma_cond) / sigma_null
wg_prv
[1] 0.2061703

Between-group PRV does the same at the teacher level:

bg_prv <- (tau_null - tau_cond) / tau_null
bg_prv
[1] 0.3413405

And a total, or multilevel, R^2 uses the combined variance:

total_null <- tau_null + sigma_null
total_cond <- tau_cond + sigma_cond

ml_r2 <- (total_null - total_cond) / total_null
ml_r2
[1] 0.3214393

Be precise about what each denominator refers to when you write these up. WG-PRV is the proportion of student-level variance explained, not the proportion of all variance. Reporting it as though it were an overall R^2 overstates your model considerably.

7.2.1 When PRV comes out negative

A negative PRV looks like an arithmetic mistake and usually is not. Adding a level-one predictor can increase the estimated level-two variance, because the level-two variance is estimated conditional on everything else in the model. If a student-level predictor is unevenly distributed across teachers, controlling for it can reveal teacher differences that were previously masked. Report the negative value and explain it. Deleting it from your table is the one clearly wrong response.

7.3 The performance package version

performance::r2(m_cond)
# R2 for Mixed Models

  Conditional R2: 0.879
     Marginal R2: 0.298

This reports marginal R^2, the variance explained by fixed effects alone, and conditional R^2, the variance explained by fixed and random effects together. These are Nakagawa’s measures, and they answer a slightly different question than the PRV statistics above. Both are defensible. Say which you used.

7.5.1 When the criteria disagree

They often will, and understanding why is more useful than memorizing a rule. AIC and BIC both penalize complexity, but BIC’s penalty grows with sample size while AIC’s does not. With a large sample, BIC prefers simpler models more aggressively than AIC does. The likelihood ratio test is a third thing again: a hypothesis test with a null of no improvement, which inherits all the usual sensitivities to sample size.

For random effects there is an additional wrinkle. Testing whether a variance component equals zero puts the null on the boundary of the parameter space, which makes the usual chi-square reference distribution conservative. The ranova() function handles this, but it is a reason not to treat a p-value of .06 on a variance component as decisive.

When the criteria disagree, say so, state which you weighted and why, and check whether your substantive conclusions change between the two models. If the treatment effect is essentially identical either way, the model choice matters less than it appears to.

7.6 When a model will not converge

Ask for two random slopes and the data may refuse:

m_two_slopes <- lmer(conflict_post ~ treat + conflict_pre_c + closeness_pre_c +
                       (1 + conflict_pre_c + closeness_pre_c | strs3),
                     data = strs, REML = FALSE)
Error: number of observations (=828) <= number of random effects (=966) for term (1 + conflict_pre_c + closeness_pre_c | strs3); the random-effects parameters and the residual variance (or scale parameter) are probably unidentifiable

This one does not merely warn. It refuses to fit at all, and the error message tells you exactly why. Asking for an intercept and two slopes for each of 322 teachers means asking for 966 random effects, and we have only 828 observations. There are more quantities to estimate than there are data points to estimate them from, so the model is unidentifiable.

It is worth doing that arithmetic yourself before fitting a complex random effects structure. Multiply the number of level-two units by the number of random effects you are requesting per unit, and compare it to your sample size. If the first number approaches the second, the model is in trouble whether or not R throws an error.

The more common situation is milder. Instead of an outright refusal you get a singular fit, a variance component estimated at essentially zero, or a correlation of exactly 1 or -1. Those are the same message delivered more politely. The data cannot support that many random effects.

The usual responses, in order of how much you give up: drop the correlations and keep both slopes uncorrelated; drop the less theoretically important slope; or return to a random intercept model and acknowledge in your write-up that slope variation could not be estimated with these data. All three are defensible. Silently reporting a singular model as though nothing happened is not.

# Uncorrelated random effects
m_uncorr <- lmer(conflict_post ~ treat + conflict_pre_c + closeness_pre_c +
                   (1 | strs3) + (0 + conflict_pre_c | strs3),
                 data = strs, REML = FALSE)
